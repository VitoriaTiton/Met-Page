ROTEIRO PARA ACESSAR O PROJETO:

- Criar uma pasta no seu computador, abrir ela com o terminal e digitar "Code .". Isso vai te enviar para o vscode.
- No vscode, abra um terminal e digita "git init" e depois "git clone https://github.com/VitoriaTiton/Met-Page.git"
- Depois você vai dar um "cd Met-Page.
- Depois você baixar o requirements: "python -m install - r requirements.txt".
- Ai depois é só dar um "python app.py" que dá certo.

Se só com a instalação do requirements não dá certo...siga o seguinte passo:

- "pip install flask"
- "python -m pip install Flask-Login"
- "python app.py"
